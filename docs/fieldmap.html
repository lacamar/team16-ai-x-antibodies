What we're given

525,063provided CDRH3 sequences — the novelty-filter set
768SPR-measured variants with real KD

Novelty rule: a CDRH3 passes if it differs at ≥2/10 positions from every provided sequence and ≥3/10 from trastuzumab. Plus len ≤ 250 and no odd cysteine count. Built + validated in novelty_filter.py.

Reading the scores

Fold-confidence numbers rank designs — they are not affinity. The lab (SPR) decides affinity.

ipTM ↑ interface placement confidence (0–1) min_ipae ↓ interface error, Å binder_pLDDT ↑ binder fold confidence (0–100)

Rank on min_ipae then iptm, and only within one folding model. Score the trastuzumab baseline through the same gates as the control to beat.
